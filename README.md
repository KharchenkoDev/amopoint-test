# CoinGecko Price Tracker

Тестовое задание: [ссылка](https://docs.google.com/document/d/10LwR5k3guN9Z45-6lnQXcdN53R17Q4keoT01mMkW4hA/edit?tab=t.0)

## О проекте

Приложение периодически получает курсы криптовалют (bitcoin, ethereum, tether) из CoinGecko API и сохраняет историю в базу данных. Доступ к данным — через REST API с пагинацией.

### Комментарии к реализации

- В качестве источника данных выбран CoinGecko API с курсами криптовалют. Это мне показалось несколько полезнее и ближе к реальным задачам, чем сервис с анекдотами из примера к заданию.
- Для запуска проекта нужен API-ключ CoinGecko. Его можно получить бесплатно, зарегистрировав демо-аккаунт на [coingecko.com](https://www.coingecko.com/). Ключ указывается в `src/.env`.
- Консольная команда не обращается к API напрямую, а запускает Job. Подобная логика в реальных проектах почти всегда требует очередей. Это позволяет повторять задачи при ошибках, распределять нагрузку и не блокировать основной процесс.
- API отдаёт данные постранично. Без пагинации база данных со временем накопила бы достаточно записей, чтобы один запрос без ограничений начал создавать проблемы.

## Структура проекта

Инфраструктура (Docker, Nginx, конфиги) отделена от приложения. Laravel-код находится в директории `src/`.

```
.
├── src/                        # Laravel-приложение
├── docker/                     # Конфиги PHP-FPM и Nginx
├── .env                        # Инфраструктурные переменные (порты хоста)
├── docker-compose.yml
├── docker-compose.prod.yml
└── Makefile
```

## Запуск

**1. Скопируй `.env`-файлы**

```bash
cp .env.example .env
cp src/.env.example src/.env
```

**2. Укажи API-ключ CoinGecko в `src/.env`**

```dotenv
COINGECKO_API_KEY=your_key_here
```

**3. Запусти установку**

```bash
make install
```

Соберёт Docker-образы, запустит контейнеры, выполнит миграции и сгенерирует `APP_KEY`.

**Ежедневная работа**

```bash
make up      # запустить контейнеры
make down    # остановить
```

## API

### `GET /api/prices`

Возвращает историю цен с пагинацией.

**Параметры запроса**

| Параметр   | Тип     | По умолчанию | Описание                                            |
|------------|---------|--------------|-----------------------------------------------------|
| `coin_id`  | string  | —            | Фильтр по монете: `bitcoin`, `ethereum`, `tether`   |
| `per_page` | integer | 50           | Записей на страницу (макс. 500)                     |
| `page`     | integer | 1            | Номер страницы                                      |

**Пример ответа**

```json
{
  "data": [
    {
      "id": 1,
      "coin_id": "bitcoin",
      "price_usd": "81236.00000000",
      "fetched_at": "2025-04-10T12:00:00.000000Z",
      "created_at": "2025-04-10T12:00:01.000000Z"
    }
  ],
  "current_page": 1,
  "per_page": 50,
  "total": 1440,
  "last_page": 29
}
```
